# GeoPulse: Hyper-Local Retail Mobility Analytics

## Project Overview

GeoPulse is a simulated geospatial analytics project designed to help retail businesses evaluate potential store locations using mobility patterns and spatial analytics.

The project demonstrates how commuter movement and store catchment areas can help identify potential customer overlap and store cannibalization.

## Objectives

- Simulate anonymized device mobility data.
- Store and process geospatial data.
- Perform spatial joins using Apache Sedona.
- Analyze hourly footfall using dbt and Snowflake.
- Visualize mobility patterns using React and Kepler.gl.
- Evaluate potential store cannibalization.
